## 2. メインフロー

### フロー1: サイト訪問 → 技法体験

```
ユーザーがサイトにアクセス（/）
  → ホームページ表示（LayerAnimationPage）
  → スクロールで3つの技法時代を体験
    ├─ 墨摺絵セクション: 墨一色のレイヤーアニメーション
    ├─ 紅摺絵セクション: 2-3色のレイヤーアニメーション
    └─ 錦絵セクション: 多色のレイヤーアニメーション
  → フッターナビゲーション
    ├─ 「浮世絵の歴史をたどる」→ /timeline へ遷移
    └─ （将来: /dawn への遷移リンク追加可能）
```

### フロー2: Dawn ページ探索

```
/dawn にアクセス（ホームからの遷移 or 直接アクセス）
  → 縦スクロールで3つの時代を順に体験
    ├─ 墨摺絵スライド（+タイトル表示）
    ├─ 紅摺絵スライド
    └─ 錦絵スライド（+エンドセクション）
  → エンドセクション
    └─ 「歴史を見る」ボタン → /timeline へ遷移
```

### フロー3: タイムライン閲覧

```
/timeline にアクセス（Dawn or ホームからの遷移）
  → 縦スクロールで時代を遷移（5時代）
    ├─ 各時代: 左下にテキストパネル + 背景にパララックス作品画像
    ├─ 作品画像クリック → 詳細モーダル表示
    │   ├─ 作品画像（拡大）
    │   ├─ 作品名、アーティスト名、説明
    │   └─ 閉じるボタン / 背景クリック → モーダル閉じ
    └─ 最後の時代を超えてスクロール → 全作品一覧グリッド表示
```

## 3. ナビゲーション構造

### 各ページ共通ヘッダー

全ページにロゴ（`/` へのリンク）と言語切替ボタンを表示。

```
[ロゴ (→ /)]          [JA | EN]
```

### ページ間遷移

```
        ┌─────────────┐
        │   / (ホーム)  │
        └──────┬──────┘
               │ フッターリンク
               ▼
        ┌─────────────┐      エンドボタン     ┌────────────┐
        │  /timeline  │ ◀─────────────────── │   /dawn    │
        └─────────────┘                      └────────────┘
```

- **ホーム → タイムライン**: フッターの「浮世絵の歴史をたどる」リンク
- **Dawn → タイムライン**: エンドセクションの「歴史を見る」ボタン
- **すべてのページ → ホーム**: ヘッダーのロゴクリック

**注**: ホームから `/dawn` への直接遷移リンクは現時点で未実装（URL直打ちでアクセス可能）。

## 4. 言語切替フロー

```
LanguageProvider（App 全体をラップ）
  → 全ページで LanguageToggle コンポーネントを表示
  → ユーザーが JA / EN をクリック
  → LanguageContext の state が更新
  → 全コンポーネントが即座に再レンダリング（ページ遷移なし）
```

- デフォルト言語: 日本語（ja）
- 切替: ヘッダー右上の JA / EN トグル
- 対象: すべてのユーザー向けテキスト（UI ラベル、作品名、説明文）

## 5. インタラクションパターン

### スクロール操作

| ページ | スクロール方式 | 説明 |
|---|---|---|
| `/` | ネイティブ縦スクロール | セクションごとにレイヤーアニメーションがトリガー |
| `/dawn` | セクション単位の縦スクロール | ホイール操作でセクション間を遷移 |
| `/timeline` | ネイティブ縦スクロール | 時代間を自然なスクロールで遷移 |

### モーダル

| トリガー | 表示内容 | 閉じ方 |
|---|---|---|
| タイムラインの作品画像クリック | 作品詳細（画像拡大 + 情報） | 閉じるボタン / 背景クリック / Escape キー |
