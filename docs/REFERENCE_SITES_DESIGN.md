## 01. 阿部守商店 (abemamoru-shouten.com)

**URL**: https://abemamoru-shouten.com/  
**スクリーンショット**: `01-abemamoru-shouten.png`

- **色使い**: 白を基調とした清潔感のある配色。ヒーローセクションは濃い茶色の木目調、フッターは穏やかな水色のグラデーション。ロゴの赤や墨絵の黒がアクセント。
- **レイアウト**: シンプルなヘッダー、全幅ヒーローイメージ、縦書き日本語テキストのセクションあり。墨絵風の魚イラストがサイト全体に散りばめられている。
- **アニメーション**: スクロール連動のフェードイン、レジーロードの可能性あり。
- **その他**: 高品質な食品写真、明朝体・ゴシック体の使い分け。
