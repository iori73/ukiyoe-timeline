## 1. 概要

| 項目 | 内容 |
|---|---|
| **プロジェクト名** | Ukiyoe（浮世絵） |
| **種別** | インタラクティブ文化展示 / Web体験 |
| **ターゲットユーザー** | 浮世絵・日本美術に興味がある一般ユーザー、教育関係者、美術愛好家 |
| **一言で言うと** | 浮世絵の版画技法の進化（墨摺絵→紅摺絵→錦絵）を、インタラクティブなアニメーションで体験できるWebサイト |

---

## 2. 目的

### 何を伝えたいか

- 浮世絵がどのように「摺り」の技術革新を経て進化してきたか
- 各時代の代表的な作品とその歴史的背景
- 版画の「レイヤー（版木ごとの色重ね）」という制作プロセスの美しさ

### なぜ Web 体験にするのか

- 静的な画像ギャラリーでは「摺りの工程」や「色の重なり」を体感できない
- アニメーションとインタラクションにより、版画制作のプロセスを直感的に理解できる
- バイリンガル対応で、日本語話者・英語話者の両方にリーチできる

## 3. ページ別スコープ

### `/` — ホーム（LayerAnimationPage）

| 項目 | 内容 |
|---|---|
| **目的** | サイト全体の導入。浮世絵の3つの技法時代を、レイヤーアニメーションで紹介する |
| **体験** | スクロールに連動して版画のレイヤーが重なっていく視覚体験。各時代のセクションで技法解説 |
| **データ** | `src/data/techniques.js` に定義された3時代（墨摺絵、紅摺絵、錦絵）の情報 |

### `/dawn` — 錦絵の黎明（DawnManualPage）

| 項目 | 内容 |
|---|---|
| **目的** | 3つの時代を縦スクロールで深掘りし、各時代の版画レイヤー構造を視覚的に体験する |
| **体験** | セクションごとのスクロールナビゲーション。各時代のスライドにレイヤー画像が重なる |
| **データ** | `src/components/dawn/ProgressTimeline.jsx` で定義された時代情報、画像レイヤー |

### `/timeline` — タイムライン（TimelinePage）

| 項目 | 内容 |
|---|---|
| **目的** | 時代ごとの代表作品を、パララックス効果のある縦スクロールギャラリーで一覧する |
| **体験** | ネイティブスクロールで時代を遷移。作品クリックで詳細モーダル表示。全作品一覧グリッド |
| **データ** | `src/data/ukiyoe.js` の PERIOD_ARTWORKS（5時代 × 複数作品） |

### `/timeline-old` — 旧タイムライン（アーカイブ）

| 項目 | 内容 |
|---|---|
| **目的** | 水平スクロール版の旧実装を保存。参考用 |
| **体験** | 横スクロールでセクションを遷移する旧UIの保存版 |

### `/logo-preview` — ロゴプレビュー（開発用）

| 項目 | 内容 |
|---|---|
| **目的** | ロゴデザインの確認・プレビュー用ページ。エンドユーザー向けではない |

## 4. データソース

| # | データ名 | 出典 | 形式 | 説明 |
|---|---|---|---|---|
| 1 | 時代・作品データ | 独自編集 | JS（`src/data/ukiyoe.js`） | 5時代の作品情報、アーティスト、説明（日英） |
| 2 | 技法データ | 独自編集 | JS（`src/data/techniques.js`） | 3技法（墨摺絵・紅摺絵・錦絵）の解説 |
| 3 | 作品画像 | Wikimedia Commons / メトロポリタン美術館 | URL参照 + ローカルレイヤー画像 | パブリックドメインの作品画像 |

---

## 5. スコープ外（明示的に作らないもの）

- **バックエンド / API**: 静的フロントエンドのみ。サーバーサイド処理なし
- **ユーザー認証 / アカウント**: ログイン機能なし
- **データベース**: すべてのデータは JS ファイルにハードコード
- **EC / 課金**: 商品販売機能なし
- **CMS**: コンテンツは開発者が直接編集
- **SNS連携**: シェアボタン、コメント機能なし
- **検索機能**: サイト内検索なし
- **アクセス解析**: Google Analytics 等の導入は任意（スコープ外）

---

## 6. 成功基準

- Figma デザインに忠実な実装（デザインQAで差異を確認）
- すべてのアニメーションが 60fps でスムーズに動作する
- 日本語/英語の完全なバイリンガル対応
- `/dawn` と `/timeline` でユーザーが直感的に操作できるナビゲーション
- 版画のレイヤー重ね合わせが視覚的に美しく表現される
- 本番ビルドがエラーなく完了する（`pnpm build`）

---

## 7. 制約事項

- **フロントエンドのみ**: バックエンドがないため、動的なデータ更新はできない
- **画像ライセンス**: パブリックドメイン / CC ライセンスの画像のみ使用可能
- **外部 API 依存**: Wikimedia Commons の画像URLに依存（可用性リスク）
- **ブラウザ対応**: モダンブラウザ（Chrome, Firefox, Safari, Edge）。IE非対応
