作品選定 ②　候補（2026-11-08）

7つの時代それぞれに、所蔵館の公開データ（The Met・シカゴ美術館・クリーブランド美術館、すべて CC0／パブリックドメイン）から候補を集めました。全件、所蔵館の API で年・所蔵番号・ライセンスを確かめています。

選び方: 使いたい作品のカードに注釈で「◯」を付けてください（目安は時代ごとに3〜6点）。赤い枠＝時代の入口の1点目の案、藍＝今のサイトの作品。題の「推定」は、所蔵館に日本語の題がなく Claude が読み下したもの（確定時に確かめます）。

今の45点: 基準に合ったのは23点。外れた22点の理由と、画像が題と違う作品が7点あったことは、いちばん下の表にあります。

01　墨摺絵

1670頃 – 1700頃　候補 15 点

Ink-only prints. All picks have AIC/Met medium text saying sumizuri-e or "ink on paper", except 2 flagged. Many AIC Moronobu/Sugimura sheets are erotic-series prints; those were excluded. Several AIC "sumizuri-e" sheets are listed as "hand-colored" (colour added later); those were avoided here so the era reads as pure ink.
