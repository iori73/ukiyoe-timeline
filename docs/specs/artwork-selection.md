## なぜ見直すか

- 今の「9時代・各5点（45点）」には、区切りの理由が記録されていない。時代の境目は CSV・`PERIOD_ARTWORKS` のキー・`periodColors.js`・Python スクリプト・`TimelineV2` のものさし・ポートフォリオの部品に手で重複している。
- 刷り物でない作品が入っている（1670-01 見返り美人図＝肉筆、1670-03 隅田川図＝屏風、1670-05＝肉筆）。サイトの導入「浮世絵の多くは町の人が買った刷り物」と食い違う。
- 時代の範囲の外の年の作品がある（1670-04＝1683、1800-04 大はしあたけ＝1857）。同じ題が2つある（歌舞伎役者図）。
- 作品に制作年・所蔵館・ライセンスの欄がない。
- 色: サイトとケーススタディは「実物から Python で抽出」と書くが、`periodColors.js` の割合は推定値と明記している。

## 決まったこと（河野さん 2026-11-08）

- 時代は**技法**で区切る（サイトの軸「技法の変遷」とトップの技法の並びに合わせる）。時代ごとの点数は固定しない。
- **刷り物だけ**（一枚摺・版本の挿絵）。肉筆画・屏風は入れない。
- 選び方: Claude が候補（選ぶ枠の約3倍）を所蔵館のメタデータつきで出し、河野さんが Figma で選ぶ。
- 制作年を全作品に足す。
- 作品のずらし（0/28/12/40/6px の繰り返し）は今のまま。日本の「粋」、非対称の感じ。

## 選定基準（案）

1. 刷り物だけ。
2. その時代の技法が画面で分かる。
3. 制作年が所蔵館の資料で確かめられる。時代の範囲の外の年の作品は入れない。
4. 公開ライセンス（CC0・パブリックドメイン）で、所蔵館・所蔵番号・作品ページの出典が取れる（The Met、シカゴ美術館、クリーブランド美術館、スミソニアン。ColBase は利用条件を確認してから）。
5. 点数は目安3〜6点。題の重複なし。画題を偏らせない。
6. 東博で見た体験（品川の雪、低い屋根の向こうの富士）につながる作品を1点以上。
7. 時代の入口に使う1点目は、その時代の技法がいちばん分かる作品。
