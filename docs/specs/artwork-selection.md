### 1801〜1829（化政期）を独立させない理由（11-08）

河野さんの問い「技法で区切るという基準に矛盾する？」→ 矛盾する。化政期を立てると、売れ方・画題（役者絵・美人画の大量出版）で区切ることになる。技法は 06 と同じなので 06 に含める。06 の候補には化政期の役者絵・美人画（歌川豊国・国貞）も入れ、「庶民の刷り物」の流れは残す。06 が長いこと自体が「技法が落ち着いた期間が長かった」という情報になる。

## 選定基準（確定 11-08。追加・削除なし）

1. 刷り物だけ。
2. その時代の技法が画面で分かる。
3. 制作年が所蔵館の資料で確かめられる。時代の範囲の外の年の作品は入れない。
4. 公開ライセンス（CC0・パブリックドメイン）で、所蔵館・所蔵番号・作品ページの出典が取れる（The Met、シカゴ美術館、クリーブランド美術館、スミソニアン。ColBase は利用条件を確認してから）。
5. 点数は目安3〜6点。題の重複なし。画題を偏らせない。
6. 東博で見た体験（品川の雪、低い屋根の向こうの富士）につながる作品を1点以上。
7. 時代の入口に使う1点目は、その時代の技法がいちばん分かる作品。

## 色の決め方（11-08、河野さん「色の選定も説明も正しくなるようにして」）

今の問題: サイトとケーススタディは「実物から Python で抽出」と書くが、`periodColors.js` の割合は推定値（コード内に明記）。使われた色（activeSlots）も手で決めている。

正しくするための方法（② の候補が決まったあと、③ で実施）:
1. **どの色の枠が使われたか（activeSlots）** は、画素からは決めない。藍とベロ藍は画素では見分けられず、紅や露草の青は退色して茶や灰に見えるため。所蔵館の記述（例: Prussian blue と書かれているか）と技法史（ベロ藍は1829年頃から）から、作品ごとに決めて根拠を記録する。
2. **割合** は、選んだ作品の画像の画素を測る。紙の地（余白）と文字の枠を除き、各画素を9つの色の枠のうち最も近いもの（CIEDE2000 の色差）に振り分けて数える。青系は 1 の結果（その作品に藍とベロ藍のどちらがあるか）で振り分ける。時代の値は作品ごとの割合の平均。
3. スクリプト（`scripts/extract_period_colors.py` を直す）は結果を JSON ファイルに書き出し、`periodColors.js` はその値から作る。手で数字を足さない。
4. 説明に書くこと: 「どの色が使われたかは作品の資料と技法史から決め、割合は画像の画素を数えた。いま残っている、退色した状態の色であり、刷られた当時の色とは違う（特に紅は薄く出る）」。
注意: 画素を測るには画像を読み込む必要がある（保存はしない）。③ の前に河野さんに確認する。
