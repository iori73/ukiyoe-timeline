# 色の割合の測定（2026-11-12）

## 何をしたか
- 対象: タイムラインの全103点（シカゴ美術館66点はリポジトリの画像、メトロポリタン美術館25点・クリーブランド美術館12点は所蔵館の公開画像を作業用の一時フォルダに取得。リポジトリには入れていない）。
- 方法: `scripts/measure_period_colors.py`（2026-11-12 版）。画像の縁から紙の地の色を推定して除き、残りの画素を、**その時代に使われた色（`src/data/v2/eras.js` の activeSlots）のうち** CIEDE2000 で最も近い枠に振り分けた。藍とベロ藍は写真では見分けられないので、ベロ藍の時代（七）の青はベロ藍、それ以前は藍とした。雲母は写真に写らない。
- 結果の数字: `docs/specs/color-proportions-2026-11-12.json`（作品ごと・時代ごと）。

## 読み方と結論
- 墨摺（一）は、墨のほかに「紙」が約3割残る。地の色から外れた、焼けた・汚れた紙の部分。
- 紅絵・漆絵（三）と錦絵の誕生（五）で「金/茶」が4割前後になる。春信の錦絵や紅絵の実際の色づかいから考えると多すぎ、**紙の焼け（黄ばみ・茶色）が金/茶として数えられている**。
- 写真は「今の褪せて焼けた状態」を写す。紅は褪せ、紙は焼けるので、画素の割合は刷られたときの色の割合にならない。
- **結論: 割合はサイトに出さない。** サイトは「どの色を使ったか」（記録と技法の歴史から）だけを見せる今の形のままにする。割合を出すなら、紙の焼けを地として除ける画像（同じ作品の複数の所蔵館の画像、または色票の入った画像）が要る。
