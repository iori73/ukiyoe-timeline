## 2. セクション別の詳細差分（新デザイン vs 現状）

### 2.1 ヘッダー

- **Figma（新）**: 左上は**角が丸い濃い灰色**のボタン/リンクで「浮世絵」。右上は円形アイコン内に「EN」。
- **現状**: `logo-square.svg` と `LanguageToggle`。ロゴの形状（角丸・色）が新デザインと一致するか要確認。

### 2.2 ヒーロー（メインビジュアル）— **レイアウトが大きく変更**

- **Figma（新）**  
  - **2カラム**:  
    - **左**: 大見出し「木版画の／印刷技法」（2行、明朝系）、その下にサブ「**最高峰の職人技が一つ一つ積み重ねて、新たな美術が生まれた**」。  
    - **右**: 木版画制作風景の**大きなイラスト**（複数の人物が作業する様子）。  
  - 中央だけの1カラムではなく、タイトルとビジュアルが横並び。
- **現状**  
  - 1カラムで、タイトルのみ中央。「木版画の／印刷技法」＋サブ「墨摺絵から錦絵へ — 色が重なり、絵が生まれる」。  
  - 右側の制作風景イラストは**なし**。
- **差分**:  
  - ヒーローを**2カラム**にし、左にタイトル＋**新しいサブ文言**、右に**制作風景イラスト**を追加する必要あり。  
  - サブは「墨摺絵から錦絵へ…」→「最高峰の職人技が…」に変更。

### 2.3 概要セクション（浮世絵紹介＋技法インジケーター）— **未実装**

- **Figma（新）**  
  - **背景**: 全幅で**藍色基調の浮世絵**（夜景・夕景の水辺、橋、船、山など）。彩度低め。  
  - **オーバーレイ**: 白文字で浮世絵の紹介文（「浮世絵は、江戸時代に開花した…」など）。  
  - **その下**: 横並びの**円形インジケーター**で「黒摺絵」「紅摺絵」「錦絵」など。タイムライン/横スクロール風。現在位置は「紅摺絵」がやや大きく下線付き。
- **現状**: 該当ブロックなし。ヒーローの次がそのまま技法セクション。
- **差分**: この**概要ブロック**（藍色背景＋白テキスト＋技法インジケーター）を新規追加する必要あり。

### 2.4 印刷技法の3セクション — **レイアウトが変更**

- **Figma（新）**  
  - 各セクションとも**同じパターン**:  
    - **左**: 浮世絵が斜めに配置された**レイヤー風イラスト**（線画＋色の層が重なって見える）。わずかに浮く影。  
      - 黒摺絵: 線画＋墨一色の層。  
      - 紅摺絵: 線画＋紅・緑の層。  
      - 錦絵: 線画＋多色の層。  
    - **右**: タイトル＋複数行の説明文。  
  - 1つ目は「**黒摺絵**」、2・3は「紅摺絵の印刷プロセス」「錦絵の印刷プロセス」。
- **現状**  
  - 各セクションは**中央**にアイソメトリックのイラスト、**下**にタイトル・サブ。  
  - 1つ目は「黒摺絵」表記で、アイソメの「落ちて重なる」アニメーションあり。
- **差分**:  
  - **レイアウト**: 中央縦並び → **左イラスト・右テキスト**の2カラムに変更。  
  - **ビジュアル**: アイソメの動きではなく、**レイヤーが重なって見える静止（または別アニメ）**。  
  - 表記は新デザインでも「黒摺絵」なので、現状の「黒摺絵」のままでよい。説明文は段落で複数行。

### 2.5 フッター

- **Figma（新）**  
  - 文言: 「**色別の製本が層になり、一枚の絵になる。**」（「製本」は「版木」の誤記の可能性あり）。  
  - その下: 横一列の**カラーチップ**（濃い灰、薄緑、ピンク、水色、黄、赤、薄緑、水色など）。  
  - CTA: 「**浮世絵の歴史をたどる →**」。
- **現状**  
  - 文言: 「色別の版木が順に重なり、一枚の絵になる。」  
  - カラーチップは**なし**。  
  - CTA: 「浮世絵の歴史をたどる →」で `/timeline` リンク。
- **差分**:  
  - フッターに**カラーチップ**を追加。  
  - 文言は現状の「版木」のままでもよい（Figmaの「製本」は誤記の可能性）。
