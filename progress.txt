## 既知の問題
- 外部画像（Wikimedia Commons ~35件、ukiyo-e.org ~10件）への依存あり（全コンポーネントで onError フォールバック済み）
- `LayerAnimationPage.css` の `.layer-anim__description::before` が Figma API URL を参照（本番で404になるが装飾のため実害なし）
- `logo_v2.svg`（8.9MB）・`original-met.jpg`（2.1MB）はコード未参照の参照ファイル（本番バンドルに影響なし）
- Lighthouse Performance 75 のボトルネックは JS 実行時間（1.5s）が主因。これは React + Framer Motion の構造的なもので、Slow 4G 環境で 90+ は困難（本番 HTTPS + CDN で改善見込み）
